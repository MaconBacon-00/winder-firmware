# NU Rocketry Filament Winder Firmware

Firmware for an adapted Contraption filament winder designed to wind NU Rocketry 4-inch tubes.

The controller is a BTT Octopus V1.1 running Marlin firmware with TMC2209 stepper drivers. The machine has 1,250 mm of working travel.

This project is based on Marlin 2.1.2.9. Build it with PlatformIO using the `STM32F446ZE_btt` environment.
